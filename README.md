## ✨ Características y Funcionalidades Interactivas

- **📱 Mobile First & 100% Responsivo:** Adaptación para dispositivos móviles, tablets y monitores de escritorio.
- **⚡ HTML5 Semántico & CSS3 Puro:** Sin frameworks pesados; transiciones suaves, elevación con sombras sutiles y bordes orgánicos.
- **🥞 Crepa Builder Interactivo:**
  - Selección dinámica de ingredientes mediante *chips* táctiles (Queso crema, Jamón, Cajeta, Chocolate Hershey's, Plátano, Nutella, Mermelada, Fresa, Nuez picada, Arándano, Lechera).
  - Selector de Punto Pick Up integrado.
  - **🎲 Botón "¡Sorpréndeme!":** Sugiere combinaciones aleatorias deliciosas con un solo clic.
  - Generación automática del mensaje de WhatsApp con la lista exacta de ingredientes y el punto de recolección elegido.
- **🥤 Carta Digital Completa:**
  - **Frappes:** Taro Frappe (firma de la casa) y Oreo Frappe.
  - **Sodas Italianas:** 8 sabores refrescantes (Maracuyá, Mango, Manzana Verde, Mora, Menta Azul, Frutos Rojos, Limonada Rosa, Dragon Fruit).
  - **Especialidades:** Taro Latte, Matcha Latte, Chai Latte, Mazapán Latte.
  - **Café de Especialidad:** Americano, Americano Limón, Café Horchata, Latte Lavanda, Caramel Latte, Moka, Latte Clásico.
  - **Tizanas:** Frutas de la Pasión.
- **🔮 Ruleta de Bebidas:** Selector aleatorio interactivo para sugerir la bebida ideal del día y pedirla de inmediato por WhatsApp.
- **💎 Sección Bracelets & Lifestyle:** Bloque editorial dedicado a la colección exclusiva de pulseras artesanales en barra.
- **🌐 Redes y Contacto:** Enlaces oficiales a Instagram (`@otrocafecitomx`), TikTok y botón flotante de WhatsApp.

## 🚀 Despliegue Local

Para previsualizar localmente:

1. Abre directamente el archivo `index.html` en tu navegador web.
2. O inicia un servidor HTTP estático con Python:
   ```bash
   python -m http.server 8080
   ```
   Y accede a `http://localhost:8080`.
